# halfmarble mods

Claude Code mods by Halfmarble LLC, in one marketplace named `halfmarble`. These mods are made by Halfmarble LLC, which
is not affiliated with, sponsored by or endorsed by Anthropic.

| Mod | What it does |
| --- | --- |
| [`usage-feed`](plugins/usage-feed/) | Sends your Claude Code plan usage and each session's state to devTopBars, the macOS menu-bar app, over a socket on your Mac. |

## Install

In a Claude Code session in a terminal:

```
/plugin install usage-feed --marketplace halfmarble/mods
```

From a shell:

```
claude plugin install usage-feed --marketplace halfmarble/mods
```

In the Claude desktop app: click + next to the prompt box, then Plugins, Add marketplace with `halfmarble/mods`, then
Add plugin.

Each mod's README says what it does, what it sends and how to remove it.
